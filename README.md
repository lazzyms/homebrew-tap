# Lazzyms Tap

## How do I install these formulae?

`brew install lazzyms/tap/<formula>`

Or `brew tap lazzyms/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "lazzyms/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
